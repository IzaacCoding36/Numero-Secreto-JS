# Número Secreto
**_Esse repositório apresenta um site com um minigame de número secreto utilizando JavaScript, de acordo com o curso da Alura_**

## Como funciona?

- O site escolhe um número aleatório e o seu objetivo é tentar descobrí-lo, inserindo o seu palpite na caixa de resposta
- Depois de seu palpite, é exibido uma resposta, se você está perto ou não da resposta correta (como uma dica)
- Assim que você acertar o número secreto, será exibido uma tela final com o número e a sua quabtidade de tentativas
